# Frosty records outside the recorded site menus

Snapshot: 13 September 2026.

## Meaning and limits

This is a reverse inventory of the local Frosty export against the current site mapping. An entry means that the exact source record has no mapped site selection. It does **not** establish that the attachment is unavailable in the game. Some entries are known attachment types, alternate rails, secondary sights, default states, or unused records. No entry below is classified as confirmed absent from the current game solely from this comparison.

Scope: every `GS_*` weapon stat record and every `Attachment_*` record under `Common/Hardware/Weapons/` in the local EBX manifest. Vehicles, gadgets, mounted weapons outside that path, legacy directories, loose UI descriptors, and records missing from this export are outside this inventory. This is not a complete live-game availability audit.

The existing 350 generic optic choices already cover 1,927 primary sight records. Those mapped records are excluded here. Secondary sight records are listed separately; their absence from the site does not make them unknown or unreleased.

## Full inventory

Each row links to the actual local XML. Names after the weapon prefix are internal source names, not asserted game menu labels.

The added columns show what we can identify from the existing export:

- **Title / Label:** English text from the AAM title pointer or the linked UI descriptor. AAM matching is stated as exact or with the slot/rail removed. A label alone does not prove current availability.
- **Same UI descriptor:** other site selections point to the exact same descriptor asset. This identifies a shared UI record, not necessarily identical mechanics.
- **Same hardware suffix:** another mapped source has the same normalized model name after the weapon and slot prefixes. These are candidates only; rail, capacity, variant, and modifier differences still need review.
- **Mapped examples:** up to three weapon/name pairs from the current site audit, followed by the number of additional pairs. These are recorded menu identities, not new live-game checks. Conflicting names remain visible.
- **No mapped example found:** the comparison found no matching descriptor or hardware suffix. This does not mean the attachment is new or unavailable.

In particular, `Extended1`, `Extended2`, and similar magazine suffixes are not universal capacities. Use the direct title or descriptor when present. Secondary sight names are not promoted to primary optic identities.
