## [site-common]
SITE CONVENTIONS: COMMON (use whenever you compare with site data)
- The site intentionally models a bare-weapon baseline. Game default loadouts matter only when they explain a concrete stat discrepancy.
- Attachment values can be choice-level fields OR per-weapon under <choice>.frostyModifiers.<siteWeaponId>.<field> (or <field>ByWeapon / weaponOverrides maps); the per-weapon value takes precedence. Check all before calling anything unmodeled.
- GS modifier bindings may be keyed by the attachment's selector GUID OR by a separate condition token (e.g. U_WPM_ERG_BurstFireActive 588728fd-2ae7-4424-aa22-45d9b3c82ba0, as in L13/L59). Search both.
- Site weapon <-> source roots: use the run-root weapon-crosswalk.json named in your brief (site id, class, internal name, GS/WB/Ability raw paths and hashes).

## [spread]
SITE CONVENTIONS: SPREAD
- Spread tier steps: the site stores the NEGATED source Field_9540bd8e hip step (source +2 -> site hipSpreadTierMod -2). ADS-move dispersion (movingAdsSpreadTierMod) keeps the source sign. GBM stance sub-branches (Field_447d6d51, Field_0a160c57) are parallel values, not factors.
- L69: the constants audit's named Sym crosswalk supports posture associations for HDA H2-H5 and ZDA Field_97ff0ca4. Do not assign posture semantics by matching equal numeric values. The current simulator exposes standing/moving only; L69 is a source candidate, not runtime proof.

## [recoil]
SITE CONVENTIONS: RECOIL
- Recoil tiers: amount = amount * amountMult^(amountExp + sum RecoilTierMods); variation = dirVar * dirVarMult^(dirVarExp + sum VariationTierMods). A site recoil tier mod equals the source ADDITIVE operand on RecoilAmountMultiplierExponent (Field_22ce7cf3) / RecoilDirectionVariationMultiplierExponent (Field_02433593), SAME sign; several bound operands may sum to one site value (L59).
- L70: existing paired M433 semi clips are a capture-sufficiency limit and do not identify recoil; do not repeat without new observable, framing or input evidence.

## [handling]
SITE CONVENTIONS: HANDLING
- Handling (L62): ADS-time steps keep the source sign on grips/barrels (adsTimeTierMod) and are negated on magazines (adsTimeTierShift); draw, sprint and ADS-move shifts are negated everywhere; sway, reload and velocity factors are stored as source values (magazine reloadSpeedTier indexes RELOAD_SPEED_MULTIPLIERS 1/1.13/1.277). Ladders and index equations: repo docs/STAT_LADDERS.md.

## [sway-optics]
SITE CONVENTIONS: SWAY AND OPTICS
- Weapon sway is a multiplicative factor (sim/applyAttachments.js weaponSwayMult). Iron-sight x0.6666667 exists only for the 56 weapons in SIGHTS iron weaponSwayMultByWeapon; the six site Sniper Rifles have no entry.
- Optic context (L94/L95): do not treat inline Class_104c2294 Field_9540bd8e values 16/24 as established ADS tier steps. Their optic interpretation is unresolved. Anti Glare's unnamed two-float tuple has component ratios only, not an established glint percentage; keep source descriptions separate from field semantics and runtime behavior.

## [hit-zones]
SITE CONVENTIONS: HIT ZONES
- L99 soldier hit capsules: Common/Gameplay/Soldier/GlacierSoldierBoneCollision (112-byte entries from raw offset 1648; two floats at +48). Serialized facts: materials Head 24, Neck 115 (grid value 1.0 on all 328 selections), Spine 25 (abdomen, equal to the limb value), limbs 26. INFERRED, not verified: the two floats as capsule length/radius, and the correspondence of the Neck capsule to the site chest zone and the Spine capsule to the site stomach zone. Unresolved: the offset frame (bone-local vs model axes), the in-game pose (only the SKE_Soldier_3P bind pose is serialized), the native hit-selection rule for overlapping capsules, and any projectile collision radius. The _TargetDummy variant differs (Head length 0.08; Neck 637, LeftArm 115) and a missing grid record does not establish a default value.
